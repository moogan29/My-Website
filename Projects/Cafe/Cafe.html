This was one of two projects I began in the third year of my Computer Science degree. The task was to individually develop a mobile application using Android Studio, for which I chose to create a café app. The application allows users to create an account, log in, and order food and drinks. I tested and ran the app on a Pixel 9 Pro XL emulator (API 35). THe main documents are HTML, styled with CSS files, and the app itself is written in Java.
If you want to download the entire project, please select the button here: Development Documentation.docx

I used SQLite to store user data, and overall there are 4 different tables. User data, Order data, Item Data and Item Catagories Data. THe system comes with inbuilt login data, and is ablwe to add, delete and amend data in all tables.
