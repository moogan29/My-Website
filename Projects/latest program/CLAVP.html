← Back

Welcome to my A-level Computer Science project! I worked on this project for the bettermost of the 2nd year of my A-levels. The project allows users to check the availability of classrooms in a school. It includes features such as booking rooms, checking room availability, and managing bookings. The program is designed to be user-friendly and efficient, making it easy for staff to find available classrooms. I got the idea for the project due to my school being affected by the COVID-19 pandemic, which led to a need for better management. The program is built using Python in IDLE and the main library used for the GUI (Graphical User interface) is named Tkinter for easy interaction. The program is specifialised for my secondary school only, and I even made enquires for it to be tested in real time by staff at the school.
