Software Development: Methods and Standards

This page contains all three parts of the project. In this project, we explored three hypothetical software development initiatives for a banking company:

1. An AI-powered chatbot designed to assist customers
2. A mobile application tailored for customer use
3. A Robotic Process Automation (RPA) system intended to streamline backend operations

The primary aim of this project is to examine the ethical and financial implications involved in software development, as well as to explore effective strategies for implementing robust security measures throughout the development process.
